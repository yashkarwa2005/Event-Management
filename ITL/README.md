# EventSphere · ITL Lab Project Package
## Event Management System using Scrum Agile Methodology
**Student:** Sangram Shinde | **Semester:** 5 | **Subject:** ITL Lab & Agile Methodologies (AM)

This directory contains the self-contained, working package for **EventSphere** for college laboratory demonstration.

### Quick Start:
1. Double-click `run.bat` (or run `python app.py`).
2. Your browser will automatically open `http://127.0.0.1:5000`.
3. To run automated tests: `python -m unittest discover tests -v`.
4. For evaluation manual and viva Q&A: Open `ITL_LAB_MANUAL.md`.
